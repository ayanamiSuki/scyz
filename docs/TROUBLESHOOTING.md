# 故障排查与维护手册 (Troubleshooting Guide)

## 1. 3D 舞台与地图标签层级遮挡问题

### 问题现象
在“贵州省及周边产销辐射地图”场景中，“黄平重安镇总厂”和“三大枢纽仓”标签立牌在部分视角下被下辖区县（如黄平县、凯里市等）的文字标签遮挡或重叠。

### 根因分析
1. **渲染器 DOM 层级冲突**：
   - `css3dRenderer` 容器被赋予 `z-index: 5`，而 `css2dRenderer` 容器被赋予 `z-index: 6`。
   - 总厂与三大仓原使用 `CSS3DSprite`（位于 `z-index: 5` 的容器内），而区县标签使用 `CSS2DObject`（位于 `z-index: 6` 的容器内）。
   - 由于 CSS2D 容器在 HTML 层叠上下文中高于 CSS3D 容器，所有区县标签在 2D 投影交叠时均无条件覆盖核心仓位与总厂立牌。
2. **同坐标与邻近坐标重合**：
   - 凯里仓与凯里市区县标签经纬度完全一致（`[107.9775, 26.583]`），导致两者重叠显示。
   - 黄平重安镇总厂与黄平县坐标极其邻近，容易产生遮挡。

### 解决方案
1. **统一浮空标签渲染体系**：
   - 将总厂与三大枢纽仓立牌重构为 `CSS2DObject`，与区县标签置于同一个 `CSS2DRenderer` 容器中。
   - 显式声明严格的 CSS 权重分级：
     - 总厂标签：`z-index: 35`（最高优先级，尊享金光，置顶显示）
     - 枢纽仓标签：`z-index: 25`（次高优先级，清晰卡片与状态）
     - 区县标签：`z-index: 10`（基础层级，半透明胶囊，`pointer-events: none`）
2. **去重与智能避让**：
   - 对与枢纽仓坐标完全重叠的区县标签（如“凯里市”）执行去重隐藏，保留核心“凯里仓”立牌，消除文字双重叠印。
   - 调整邻近区县标签的垂直锚点，避免向上穿透核心仓标。
